🎯 Objetivo del Toolkit

Ofrecer plantillas prácticas, listas para clase o taller, que persisten en el navegador (localStorage) y permiten importar/exportar JSON para evidencias, iteraciones y co‑diseño.

  • Estándares claros (INVEST, Gherkin, fases/touchpoints).
  • Visualizadores integrados para conversar sobre la experiencia.
  • Impresión rápida para PDFs u hojas de evidencia.

🧭 Flujo recomendado

  1. Redacta 3–5 Historias de Usuario clave (INVEST + criterios).
  2. Convierte una historia prioritaria en Línea de Tiempo (hitos con necesidad/emoción/pensamiento).
  3. Integra las interacciones y Viajes de Usuario por fases y touchpoints.
  4. Exporta JSON en cada plantilla como evidencia y compártelo con tu equipo o en clase.

💾 Persistencia & Privacidad

Los datos se guardan localmente en tu navegador (localStorage). Si cambias de equipo o navegador, usa Exportar JSON para portarlos y Importar JSON para continuar.
